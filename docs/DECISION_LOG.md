# Proyecto · Retail Banking Customer Intelligence

## Registro de Decisiones

---

## DD-001 · Selección del dataset

**Estado:** ✅ Aprobada

**Descripción**

Se selecciona un dataset bancario relacional sintético compuesto por clientes, cuentas, tarjetas, préstamos, comercios, sucursales y transacciones.

**Justificación**

Permite desarrollar un proyecto de Business Intelligence completo utilizando SQL, Python y Power BI, manteniendo relaciones coherentes entre las entidades.

**Impacto**

Define la estructura de todo el proyecto.

---

## DD-002 · Enfoque del proyecto

**Estado:** ✅ Aprobada

**Descripción**

El proyecto se desarrollará como una solución de Business Intelligence orientada al análisis descriptivo.

**Justificación**

El objetivo es apoyar la toma de decisiones mediante el análisis de datos y no desarrollar modelos predictivos.

**Impacto**

Quedan fuera del alcance Machine Learning y modelos de IA.

---

## DD-003 · Metodología de desarrollo

**Estado:** ✅ Aprobada

**Descripción**

Todo el proyecto seguirá la metodología:

Diseñar → Implementar → Ejecutar → Analizar → Documentar

**Justificación**

Garantiza un desarrollo ordenado, evita improvisaciones y mejora la trazabilidad.

**Impacto**

No se implementará ninguna fase sin haber aprobado previamente su diseño.

---

## DD-004 · Usuario final

**Estado:** ✅ Aprobada

**Descripción**

La solución estará orientada a la Dirección de Banca Minorista.

**Justificación**

Todas las decisiones de diseño deberán aportar valor a este perfil de usuario.

**Impacto**

Las Business Questions y el dashboard se diseñarán pensando en sus necesidades.

---

## DD-005 · Alcance funcional

**Estado:** ✅ Aprobada

**Descripción**

El proyecto se centrará exclusivamente en el análisis de clientes, productos y actividad financiera.

**Justificación**

Mantener un alcance realista y alineado con el dataset disponible.

**Impacto**

Quedan excluidos fraude, Machine Learning y sistemas de recomendación.

---

## DD-006 · Arquitectura del proyecto

**Estado:** ✅ Aprobada

**Descripción**

El proyecto se organizará siguiendo un flujo completo de Business Intelligence compuesto por las siguientes fases:

- SQL Analytics
- Python Analytics
- Power BI Analytics
- Business Insights & Recommendations

**Justificación**

Esta arquitectura garantiza la trazabilidad completa desde los datos originales hasta la formulación de recomendaciones de negocio, manteniendo una separación clara entre el análisis, la preparación de datos y la comunicación de resultados.

**Impacto**

La estructura del repositorio, la documentación y el desarrollo del proyecto siguen este flujo de trabajo para asegurar la coherencia metodológica.
