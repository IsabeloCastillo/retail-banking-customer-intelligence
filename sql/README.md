# SQL Analytics

Esta carpeta contiene los scripts SQL utilizados para responder las Business Questions definidas durante la fase de diseño del proyecto.

Los análisis están organizados por áreas de negocio y siguen una estructura común:

- Business Question
- Business Value
- Consulta SQL
- Key Insight
- Business Recommendation

## Contenido

| Script | Área de análisis |
|--------|------------------|
| `01_customer_intelligence.sql` | Perfil de clientes y evolución de la captación. |
| `02_product_intelligence.sql` | Adopción de productos financieros y nivel de vinculación. |
| `03_financial_activity_intelligence.sql` | Actividad transaccional y volumen económico. |
| `04_business_relationships.sql` | Relaciones entre perfil del cliente, productos y actividad financiera. |

## Objetivo

Transformar preguntas de negocio en análisis SQL que permitan obtener información útil para la toma de decisiones comerciales y estratégicas.
